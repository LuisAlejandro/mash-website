# Guía de descubrimiento para agentes

Empieza por el [índice para asistentes de Mash](/es/llms.txt). Es el punto de
entrada preferido para datos concisos y citables del producto.

## Superficies canónicas

- [/es/llms.txt](/es/llms.txt) — punto de partida preferido
- [/es/llms-full.txt](/es/llms-full.txt) — corpus completo de la documentación
- [/es/index.md](/es/index.md) — la página de inicio en Markdown
- [/es/ai.txt](/es/ai.txt) — política completa de acceso y cita
- [/sitemap.xml](/sitemap.xml) y [/robots.txt](/robots.txt)
- [/api/search](/api/search) — índice de búsqueda de la documentación
- [/api/mcp](/api/mcp) — punto de acceso MCP de solo lectura
- `/es/docs/*.md` — versiones Markdown de la documentación
- `/es/` — pide `Accept: text/markdown` para la página de inicio en Markdown
- [Catálogo de la API](/es/.well-known/api-catalog) y
  [permisos para agentes](/.well-known/agent-permissions.json)

Cuando el blog está activado, sus fuentes y sus API JSON aparecen en el catálogo
de la API. El blog se publica solo en inglés.
