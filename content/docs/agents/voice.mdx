---
title: Dictation with Pi Voice
description: Speak a prompt, review its text, then send it to Pi.
---

Pi Voice turns speech into an editable prompt. At first launch, you can select one or more dictation languages and a **Best** or **Fast** model; the wizard downloads the chosen model. If you skipped this step, open Pi and run `/voice` to complete Pi Voice's onboarding later.

## Record a prompt

In a Pi pane, start dictation with **⌃⌥Z** on macOS Mash/Cursor-style mode, or use Pi Voice's `/voice` command. Speak naturally, stop recording, then **read and edit the transcript** in Pi's message box before sending it. Transcription is not the same thing as sending a prompt.

The Linux quick-reference does not claim a distinct Mash dictation chord; use the command from Pi instead of guessing one. Native mode keeps Pi's own bindings, so use the command or Pi Voice's in-app guidance. If recognition is poor, revisit the languages and model selected for your speech. The wizard can skip dictation without affecting the terminal, editor, or agent.
