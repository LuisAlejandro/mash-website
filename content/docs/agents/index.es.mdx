La disposición Dev de Mash pone Fresh y Pi uno al lado del otro. Pi se ejecuta como un **agente de Herdr con seguimiento**, no como un simple comando de shell: Herdr puede mostrar si está inactivo, trabajando o bloqueado, asignarle un nombre en vivo en la barra lateral y seleccionarlo como destino de las peticiones. Abre una pestaña **Agent** si quieres solo Pi en un panel.

## Trabajar con el agente

Describe la tarea en el cuadro de mensaje de Pi, inspecciona en Fresh los archivos que edita y deja la aprobación final en una [pestaña de revisión](/es/docs/editor/review/). Pi puede usar herramientas para leer, editar y ejecutar comprobaciones, pero los cambios que propone siguen en tu árbol de trabajo hasta que decidas confirmarlos. Puedes abrir otro [espacio de trabajo](/es/docs/workspaces/) para una tarea independiente.

Los controles de la petición de Pi en modo Mash incluyen **Esc** para interrumpir, **Shift+Tab** para alternar el nivel de pensamiento, **Ctrl+O** para expandir la salida de las herramientas, **Ctrl+P** para alternar los modelos, **Ctrl+G** para el editor externo y **Ctrl+Shift+F** para buscar en la transcripción actual (referencia rápida de macOS). Consulta la [configuración de modelos](/es/docs/agents/providers/) y los [mapas de teclas de la plataforma](/es/docs/reference/keybindings-macos/) para las teclas que te corresponden.

Para un trabajo que se puede repartir entre agentes, usa la [orquestación](/es/docs/agents/orchestration/). Para retomar una conversación anterior, usa la [búsqueda de sesiones](/es/docs/agents/sessions/); para probar otra dirección a partir de una petición anterior, [bifúrcala](/es/docs/agents/forking/). Para peticiones de voz a texto, consulta el [dictado](/es/docs/agents/voice/).
