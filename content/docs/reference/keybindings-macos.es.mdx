---
title: Atajos de macOS
description: Atajos al estilo Mash / Cursor en Mac con Apple silicon.
---

Este es el **preajuste al estilo Mash / Cursor** elegido en el primer inicio (el predeterminado), transcrito de la guía rápida de macOS incluida en la aplicación. Si elegiste **Nativo**, usa el [mapa nativo](/es/docs/reference/keybindings-native/). Los menús de Mash Terminal muestran las teclas del modo que elegiste.

## Espacios de trabajo

| Acción                                               | Teclas    |
| ---------------------------------------------------- | --------- |
| Nuevo espacio de trabajo con perfil de disposición   | ⌘⌃N       |
| Nuevo worktree con perfil de disposición             | ⌘⌃⇧N      |
| Renombrar espacio de trabajo                         | ⌘⌃R       |
| Cerrar espacio de trabajo                            | ⌘⌃W       |
| Eliminar worktree (borra el checkout tras confirmar) | ⌘⌃⌫       |
| Espacio de trabajo anterior / siguiente              | ⌘⌃[ / ⌘⌃] |
| Cambiar al espacio de trabajo 1–9                    | ⌘⌃1–9     |
| Ir a la sesión                                       | ⌘⌃G       |
| Selector de espacios de trabajo                      | ⌘⌃O       |

| Pestaña anterior / siguiente                            | ⌘⇧[ / ⌘⇧]             |
| Cambiar a la pestaña 1–9                                | ⌘⇧1–9                 |
| Renombrar / cerrar pestaña                              | ⌘⇧M / ⌘⇧W             |
| Enfocar panel a la izquierda / abajo / arriba / derecha | ⌘⌥← / ⌘⌥↓ / ⌘⌥↑ / ⌘⌥→ |
| Recorrer paneles anterior / siguiente                   | ⌘⌥[ / ⌘⌥]             |
| Dividir vertical / horizontal                           | ⌘⌥\ / ⌘⌥-             |
| Cerrar / ampliar panel                                  | ⌘⌥W / ⌘⌥Z             |
| Modo de cambio de tamaño                                | ⌘⌥R                   |
| Nuevo panel de shell bajo Fresh                         | Ctrl+Shift+Backtick   |

| ------------------------------------------------------------------------- | --------- |
| Agente anterior / siguiente                                               | ⌃⇧↑ / ⌃⇧↓ |

| Pi: interrumpir / limpiar o salir                                         | Esc / ⌃C  |
| Pi: cambiar el nivel de razonamiento / expandir la salida de herramientas | ⇧Tab / ⌃O |

| Fresh: abrir / guardar                                                    | ⌘O / ⌘S   |

| Fresh: añadir cursor a la siguiente coincidencia                          | ⌘D        |
| Fresh: copiar ruta del archivo / duplicar línea                           | ⌘⌥C / ⌥⇧↓ |

## Herramientas y aplicación

| Acción                                                                | Teclas         |
| --------------------------------------------------------------------- | -------------- |
| Control de versiones / estado de contenedores                         | ⌃⇧G / ⌘⇧O      |
| Fragmentos / buscador de archivos / paleta de comandos                | ⌘⌥P / ⌘P / ⌘⇧P |
| Búsqueda de sesiones                                                  | ⌘⌥L            |
| Capturar / pegar anotaciones                                          | ⌘K / ⌘L        |
| Gestionar anotaciones                                                 | ⌘⇧L            |
| Elegir enlace o ID                                                    | ⌥G             |
| Gestor de plugins / bifurcar desde un mensaje                         | ⌘⇧X / ⌘⌥Y      |
| Ayuda / ajustes                                                       | ⌘⇧I / ⌘I       |
| Desvincular / recargar configuración                                  | ⌘U / ⌘R        |
| Buscar actualizaciones                                                | ⌘⇧U            |
| Abrir destino de la notificación / mostrar u ocultar la barra lateral | ⌘Y / ⌘B        |

Cerrar pestañas y eliminar worktrees no se puede deshacer. Para cambiar una tecla después de la configuración inicial, edita la configuración modificable, pero ten en cuenta que el elemento del menú de Mash Terminal sigue enviando su atajo original. Consulta [configuración](/es/docs/reference/configuration/).
