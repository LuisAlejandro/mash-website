---
title: Notifications and status
description: Follow activity, PR status, and Mash update notices.
---

Herdr can show notifications for an agent or a plugin action. **Open notification target** jumps to the pane or workspace associated with a notification; on the Mash keymap it is **⌘Y** on macOS or **Ctrl+Alt+Y** on Linux. In Native mode use **Ctrl+B**, then **o**.

Mash includes a PR Watch plugin that polls PR badges and branch ahead/behind counts while it runs, and refreshes a workspace when you focus it. The agent sidebar can also show prompt-cache usage from the bundled Cache Hit plugin. These are _status displays_, not approval or a substitute for [reviewing a diff](/docs/editor/review/).

A new Mash release may produce an update notice. On Ubuntu it tells you how to upgrade with APT; on macOS it can offer a verified in-app update or point you to the release page. [Update Mash](/docs/updates/) has the platform-specific steps. If a notification doesn't open, check that its target pane or workspace is still running; [session search](/docs/agents/sessions/) can recover earlier Pi conversations.
