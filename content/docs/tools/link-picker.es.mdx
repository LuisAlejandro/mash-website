---
title: Elegir un enlace o ID
description: Selecciona una ruta, una URL o un identificador impreso en un panel.
---

Cuando un agente imprime una ruta de archivo, una URL, un hash, una dirección IP o un UUID, no necesitas volver a escribirlo. Enfoca el panel con el texto e invoca **Elegir enlace o ID**. El selector incluido en Mash lee el texto visible del panel enfocado, resalta las coincidencias con pistas de letras cortas y te permite elegir una para copiarla al portapapeles.

| Acción             | Teclas Mash en macOS | Teclas Mash en Linux | Nativo          |
| ------------------ | -------------------- | -------------------- | --------------- |
| Elegir enlace o ID | ⌥G                   | Alt+G                | Ctrl+B, luego u |

El selector analiza el panel que estás viendo, no todos los búferes ni las sesiones anteriores. Si un elemento se ha desplazado fuera de la vista, vuelve a la salida del panel o usa la [búsqueda de sesiones](/es/docs/agents/sessions/) para encontrar un mensaje anterior de Pi. Para un archivo que ya está en el proyecto, el [buscador de archivos](/es/docs/editor/files-and-search/) lo abre sin necesidad de copiar una ruta. El selector es una acción de plugin de Herdr, así que también se puede encontrar en la [paleta de comandos](/es/docs/tools/command-palette/).
