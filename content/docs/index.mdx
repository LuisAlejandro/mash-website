Mash combines a terminal, Herdr workspaces, the Fresh editor and Pi into one desktop workspace for AI-assisted coding. The app's settings and sessions live under `~/.mash`, separate from the tools you use outside Mash.

## Start here

1. [Install Mash](/docs/installation/) for your platform.
2. [Complete first launch](/docs/first-launch/) to choose tools, a provider, shortcuts, and optional dictation.
3. [Create a workspace](/docs/workspaces/) and use its editor and agent together.
4. [Review a change](/docs/editor/review/) before deciding what to commit.

## Explore the app

- [Workspaces and tabs](/docs/workspaces/): separate tasks, worktrees, layouts, tabs, and panes.
- [Agents and sessions](/docs/agents/): Pi, providers, voice, session navigation, and orchestration.
- [Editing and review](/docs/editor/): Fresh, file navigation, source control, and annotations.
- [Terminal and tools](/docs/tools/terminal/): command palette, plugins, notifications, and add-ons.
- [Reference](/docs/reference/configuration/): shortcuts, configuration paths, and troubleshooting.

These pages describe the app on its current release; [the releases page](https://github.com/LuisAlejandro/mash/releases/latest) always has the latest installer. Shortcuts depend on the platform and the keybinding mode selected at first launch.
